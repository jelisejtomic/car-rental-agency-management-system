# Car Rental Agency Management System

This project is a console-based Java application built with Eclipse IDE, implementing fundamental principles of object-oriented programming.

## Features

Data is stored in CSV files.

-   Client: Can log in, request a vehicle, and extend existing rentals.

-   Agent: Can log in, register clients, add and remove vehicles, approve new and extended rental requests, and manage vehicle returns.

## Project Information

This project was developed for the course _Object-Oriented Programming 1_.
